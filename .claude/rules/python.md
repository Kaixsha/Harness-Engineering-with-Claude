# Python Source Rules

These instructions apply to Python files under source directories.

- Use descriptive function and variable names.
- Keep functions small and focused on one responsibility.
- Use docstrings for public functions.
- Validate inputs at application boundaries.
- Separate deterministic business rules from model guidance.
- Raise explicit errors for unsupported states.
- Avoid hidden global state.
